# 📣 LeetCode Feedback Portal

**Languages**: [English](./README.md) | [简体中文](./README-CN.md)

Welcome to the **LeetCode-Feedback** repository!

This space provides a transparent and organized way to report content-related issues you've encountered on [LeetCode.com](https://leetcode.com) or [LeetCode.cn](https://leetcode.cn).

By submitting issues here, you help improve the accuracy, clarity, and quality of LeetCode's learning platform for everyone.

---

## 📌 What Types of Issues Can You Report?

You can report problems under the following categories:

### 🔍 Problem Content Issues
- 🔹 Incorrect or unclear **problem descriptions**
- 🔹 **Solved examples** that are wrong or misleading
- 🔹 Incorrect or missing **constraints**
- 🔹 Issues with **hints**
- 🔹 Inaccurate or unrelated **related topics**
- 🔹 **Incorrect test cases**
- 🔹 **Missing edge test cases** that should be included

### ✍️ Editorial Content Issues
- 🔸 Missing or unclear **solution approaches**
- 🔸 Errors in **editorial videos**
- 🔸 **Editorial code** that fails to compile or run
- 🔸 **Figures or animations** that are broken, missing, or misleading

---

## ⚠️ What Should NOT Be Reported Here?

For **non-content issues** such as:

- Billing/account problems  
- Site performance  
- Contest concerns  
- General support requests  

👉 Please visit our [Help Center](https://support.leetcode.com/hc/en-us) to get direct assistance.

---

## 🙌 How to Contribute

1. Navigate to the **[Issues tab](https://github.com/LeetCode-Feedback/LeetCode-Feedback/issues)** of this repo.
2. Choose a relevant template (e.g., “Bug Report”, “Missing Test Case”).
3. Clearly describe the issue and include links/code snippets where applicable.
4. Submit!

---

Thank you for helping make LeetCode better! 💙
